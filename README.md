# Neuroukładanka · Нейроскладанка

**PL** · Interaktywna gra o mózgu i zachowaniu. Każdy poziom ma dwa etapy: **Odkrywaj** (model, którym sterujesz: potencjał czynnościowy, synapsa i leki, płaty mózgu, układ autonomiczny, oś stresu, EEG, LTP i inne) oraz **Zadanie** (ułóż schemat, kolejność lub dopasuj pojęcia).

**UA** · Інтерактивна гра про мозок і поведінку. Кожен рівень має два етапи: **Досліджуй** (модель, якою ти керуєш: потенціал дії, синапс і ліки, частки мозку, вегетативна система, вісь стресу, ЕЕГ, LTP та інше) і **Завдання** (склади схему, послідовність або зістав поняття).
